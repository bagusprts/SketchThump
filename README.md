# SketchThump

Enhances real-time collaboration and multi-threaded rendering through a scalable, distributed architecture builder platform.

SketchThump is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/SketchThump.git`
2. `cd SketchThump`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
